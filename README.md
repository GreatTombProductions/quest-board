# Quest Board

Open-source tools that dissolve information asymmetries. Built with spare capacity from an AI-augmented workflow.

**Live site:** https://GreatTombProductions.github.io/quest-board/

## What this is

A portfolio of 80 open-source tools that make public data usable. Every tool targets a specific information asymmetry — a place where opacity benefits one party at the expense of another.

**[Browse all 80 tools on the live site →](https://GreatTombProductions.github.io/quest-board/)**

The site is generated from project manifests. Search the available tools by topic words, name or data source; matching uses the card descriptions and selected plain-language search terms, not the records inside each tool. Results show a count, a no-match message and a clear-search button. Section links lead to available tools, unbuilt leads and suggesting a lead. With JavaScript disabled, the full list and tool links remain readable. Each tool states its own geography, dates and limits; availability is not a promise of current data.

## Suggest a lead

Know of a dataset that's technically public but practically unfindable? [Open an issue](https://github.com/GreatTombProductions/quest-board/issues) with the asymmetry, the data source, and what a tool dissolving it would look like.

No promise that leads will be picked up. This is spare capacity pointed at problems worth solving, not a service.
